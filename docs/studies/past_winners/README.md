# Past Winners Study Lab

> Study winners until good patterns look obvious and bad risk:reward feels uncomfortable.

This is a dedicated study section (not playbook content) for building deep pattern memory from historical winners.

## What This Section Contains

- `docs/studies/past_winners/README.md` - study hub and workflow
- `docs/studies/past_winners/WINNER_ENTRY_TEMPLATE.md` - structured note template per stock
- `docs/studies/past_winners/DAILY_REVIEW_LOOP.md` - daily/weekly drill process
- `trade_data/past_winners/catalog.json` - saved winner entries
- `trade_data/past_winners/glossary.json` - pattern wisdom and stats
- `docs/assets/past-winners/` - chart images and annotations

## Core Study Goal

Train your subconscious pattern recognition for:
- setup quality,
- entry timing,
- stop and invalidation,
- risk:reward,
- position sizing,
- exit behavior,
- market context fit.

## How To Save One Winner

1. Save chart images (`before`, `breakout`, `exit`, `annotated`) into `docs/assets/past-winners/`.
2. Add one structured entry in `trade_data/past_winners/catalog.json`.
3. Add key learning tags (`tightness`, `volume-dry-up`, `first-stage-base`, `late-stage-fail`, etc.).
4. Update glossary stats weekly in `trade_data/past_winners/glossary.json`.

## Minimum Fields (non-negotiable)

- Pattern + variation
- Trigger / entry / stop / invalidation
- Position size logic (R-based)
- Market regime + sector context
- RS + ADR + breakout volume quality
- Exit logic + realized R
- Two lessons

## Quick Rule

No screenshot without structured notes.
No structured notes without trigger + invalidation + sizing.
