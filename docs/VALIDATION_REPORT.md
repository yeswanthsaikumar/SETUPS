## 8. Remaining gaps / recommendations

1. **Install Playwright in CI** so the 76 browser-level UI tests run as part
   of the normal gate. They cover the Trade Board, Wisdom panel, breadth /
   sector HTML pages — surface areas our API tests can't reach.
2. **Mutual funds provider** (`mutual_funds_provider.py`) and
   **fundamentals provider** (`fundamentals_provider.py`) are covered only
   by network-marked tests. Add a thin VCR-style fixture that records real
   responses once and replays them, so drift in the upstream API shape is
   caught without live hits.
3. The industry-groups test suite runs against an **empty temp cache**, so
   the compute path returns `groups=[], bgRefreshing=true`. A future
   enhancement is a tiny fixture that seeds ~20 CSVs across 3 industries
   so we can assert non-empty rsRank / rsScore / breadthScore fields.
4. **Golden snapshots** are only "key-shape" checks (types, not values).
   For high-stakes endpoints (`/api/wisdom/pulse`, `/api/sector-rotation`)
   consider a second layer that pins a few numeric invariants
   (e.g. `rsScore` must be in `[-100, 100]`).
5. **Performance budgets** (T-22 / T-23 / C-03) only bound the fast paths.
   Add a nightly perf run that times a realistic industry-groups compute
   with the full 2,600-CSV cache and asserts < 15 s wall-clock.
