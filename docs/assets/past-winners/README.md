# Past Winners Image Assets

This folder stores chart snapshots for the dedicated study lab:

- `docs/studies/past_winners/README.md`
- `docs/studies/past_winners/WINNER_ENTRY_TEMPLATE.md`
- `trade_data/past_winners/catalog.json`

## Naming Convention

- `SYMBOL-YYYYMMDD-before.png`
- `SYMBOL-YYYYMMDD-breakout.png`
- `SYMBOL-YYYYMMDD-exit.png`
- `SYMBOL-YYYYMMDD-annotated.png`

Example:
- `MCX-20250502-breakout.png`

## Minimum Annotation On `-annotated` Image

- pattern label + variation
- trigger line
- stop/invalidation line
- entry mark
- first objective or trail rule note
- one context note (market/sector/RS)
